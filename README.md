# Painel Executivo de Transição Previdenciária do Maranhão

Pacote público mínimo da demonstração Streamlit. Não contém login, documentos, PDFs, roadmap, testes, logs, inventários, backups ou bases XLSX de origem.

Entrada da aplicação: `frontend/app.py`.

Execução local: `streamlit run frontend/app.py`.
